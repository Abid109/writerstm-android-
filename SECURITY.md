# Security Policy

## Supported Versions

Security updates are currently provided for the latest version of
Writerstm Stream available in this repository.

| Version | Supported |
| ------- | --------- |
| Latest  | Yes       |
| Older versions | No |

## Reporting a Vulnerability

If you discover a security vulnerability in Writerstm Stream, please
report it privately to the project maintainer before publicly
disclosing it.

Please do not create a public GitHub issue for security vulnerabilities.

When reporting a vulnerability, please include:

- A clear description of the vulnerability
- The affected feature or file
- Steps to reproduce the issue
- The potential impact
- Any relevant screenshots or logs that do not contain private information

## What Happens After a Report

We will review the report and determine whether it represents a
security vulnerability.

If appropriate, we will work on a fix and release an updated version
of the project.

Please allow reasonable time for investigation and remediation before
public disclosure.

## Sensitive Information

Do not include passwords, API keys, access tokens, personal information,
or other private credentials in a security report.

If credentials are accidentally exposed, revoke or rotate them
immediately where possible.

## Scope

This policy applies to the Writerstm Stream website and Android
application contained in this repository.

Third-party services, APIs, websites, media providers, and external
infrastructure are outside the direct control of this project and may
have their own security reporting procedures.
